# Advent of Code 2023

My solutions to [Advent of Code 2023](https://adventofcode.com/2023), the yearly December run of daily programming puzzles. I do it as a fun warm-up exercise, usually until the puzzles start eating my evenings.

**Language:** JavaScript (Node.js)
**Progress:** Days 1–5

## Layout

Each day has its own folder (`1/` through `5/`) with an `app.js` that solves both parts and prints the answers.

## Running

Puzzle inputs are personal to each Advent of Code account, so they aren't committed. Save your input as `data.txt` in the day's folder, then run the script from the repo root:

```bash
node 1/app.js
```
